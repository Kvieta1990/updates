- The `pystog_cli` engine for total scattering data processing now supports the uncertainty calculation for pair distribution function (PDF). The utility is available on ORNL Analysis cluster and users can also set up the utility locally -- see the GitHub repo [here](https://github.com/neutrons/pystog).

- The uncertainty calculation for PDF is not supported in the autoreduction pipeline for both NOMAD and POWGEN.
